# Web interface

I use record-shop labels, crate dividers and liner notes as visual references
for Sideband's interface. Recommendations include the signals that contributed to each match.

## Recommendation meter

The bar beneath a recommendation shows positive signals in teal and negative
signals in vermilion. An ink tick marks the net score. The "Why this match" table
provides the same information as text. A yellow label shows the match percentile.

## Typography

Young Serif is used for headings and artist names, Schibsted Grotesk for interface
and body text, and IBM Plex Mono for figures in tables, ranks and charts.

## Colour

Tokens are in `musicfinder/web/style.css`. Light and dark modes have separate
palettes. Backgrounds use paper and ink colours, with a marigold accent. Positive
and negative signals use `#009488` and `#C4471F` in light mode, and `#1AA396`
and `#D9653C` in dark mode.

## Layout conventions

For interface contributions, use flat surfaces and a single level of cards. Icons use SVG rather than emoji.
Charts use one scale per axis and keep labels readable without labelling every
mark. Reserve evidence colours for data. Published copy should describe features
the app has; testimonials and usage counts need a source.
